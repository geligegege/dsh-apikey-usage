# 截图目录

README 里的两张图引用固定为：

| 文件 | 用在哪 | 建议尺寸 | 拍什么 |
| --- | --- | --- | --- |
| `sidebar.png` | 左侧栏入口 | 420 × 900（窄条） | 侧栏展开状态，能看出图标排在「插件」「日程」之后，最好带上 tooltip/标题「API Key 用量」 |
| `panel.png` | 用量面板全貌 | 1600 × 1000 或更宽 | 主区完整面板：标题、范围切换、四个汇总卡片、至少两张 Key 卡片（含柱状图与明细表）、价目设置展开状态 |

当前这两张是**占位图**（灰底虚线框 + 文字），仅用于让 README 不出现坏图。替换步骤：

1. 用系统截图工具截取 DSH 窗口（建议窗口宽度 ≥ 1400px，深色主题更贴近默认观感）。
2. 按上表**同名覆盖**这两个文件（PNG）。
3. 刷新 GitHub 页面即可看到新图，无需改 README。

可选补充（想在 README 里加时再引用）：

| 文件 | 用途 |
| --- | --- |
| `panel-dark.png` / `panel-light.png` | 深色/浅色两套面板截图，做主题对比 |
| `prices.png` | 价目设置区域特写 |
| `empty.png` | 无数据时的空状态 |

## 拍摄注意

- 截图里**不要出现真实 API Key**：面板只显示凭据名（如 `KSYUN_API_KEY`），本身安全；但侧栏/标题栏若露出账号信息或其它窗口内容，请先打码。
- 数字可以是演示数据；如果不想暴露真实用量，可先在一个干净 profile 里发几轮对话再截图。
- 压缩：PNG 控制在 500 KB 以内（面板图通常 100–300 KB），必要时用 `pngquant`/`oxipng` 压一下。
